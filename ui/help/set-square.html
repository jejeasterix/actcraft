Équerre

L'équerre est un triangle rectangle gradué qui se pose sur la page.

Le choisir

Menu Outils, sous-menu Outils de maths, entrée Équerre.

S'en servir

Glissez l'équerre pour la placer et tournez-la pour l'orienter. Le stylo accroche son trait sur les côtés de l'équerre, ce qui donne des perpendiculaires et des angles précis.
