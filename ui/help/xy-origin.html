Repère XY

Le repère XY marque sur la page un point de référence, une croix dans un disque, autour duquel les objets tournent.

Le choisir

Menu Outils, sous-menu Outils de maths, entrée Repère XY.

S'en servir

La commande montre ou cache le repère ; son entrée est cochée tant qu'il est visible. Glissez le disque pour le déplacer : sa position est gardée pour chaque page. Tant qu'il est visible, les objets que l'on fait pivoter tournent autour de lui.
