Modes du toucher

Le mode du toucher décide ce que fait un doigt posé sur la page. Le stylet et la souris conduisent toujours l'outil courant, quel que soit le mode.

Le changer

Menu Affichage, entrée Mode du toucher : un sous-menu propose quatre choix exclusifs, le mode actuel est coché. C'est un réglage du poste : il est gardé d'une session à l'autre. Un changement demandé pendant un contact attend le relâché.

Les quatre modes

  • Ignorer le toucher : les doigts ne font rien.
  • Le doigt écrit : un seul doigt à la fois conduit le stylo ; aucun geste.
  • Le doigt sélectionne : un seul doigt à la fois conduit l'outil de sélection ; aucun geste.
  • Gestion complète (réglage par défaut) : un doigt conduit l'outil courant comme le stylet ; deux doigts posés ensemble déplacent ou zooment la page.

Dans les modes « Le doigt écrit » et « Le doigt sélectionne », une paume posée pendant que le stylet est sur l'écran, ou un doigt de plus, est ignorée.

En mode à deux utilisateurs, le mode du toucher ne s'applique pas : le doigt prend l'outil de son utilisateur.
