Capture d'une fenêtre

Cet outil capture une fenêtre entière du bureau.

Le choisir

Menu Outils, sous-menu Caméra, entrée Capture d'une fenêtre.

S'en servir

Dans la fenêtre de sélection qui recouvre l'écran, la fenêtre située sous le pointeur est celle qui est retenue : appuyez sur celle que vous voulez, puis choisissez la destination dans la palette.

Réglages

Destination : « Page actuelle », « Nouvelle page » ou « Presse-papiers », par les boutons de la palette « Caméra ». La capture n'existe que sur Windows, macOS et Linux.
