Cadre web

Le cadre web montre une page de site sur la page du document. Il se pose par le menu Insertion, sous-menu Lien, entrée Cadre web : saisissez une adresse ou du code HTML.

Glisser une vidéo vers la page

Une vidéo du cadre web se lit mieux sur la page que dans le cadre : le lecteur d'ActCraft joue les vidéos H.264, ce que le cadre ne sait pas toujours faire.

  1. Dans le cadre, repérez un lien direct vers un fichier vidéo (.mp4, .webm, .mov ou .m4v) ou une vidéo intégrée à la page.
  2. Glissez ce lien ou cette vidéo hors du cadre, sur la page du document, à l'endroit voulu.
  3. ActCraft télécharge la vidéo et la pose sur la page comme un objet vidéo, avec une image de remplacement. Elle est rangée dans les ressources du document et suit l'annulation en une seule étape.

Si le téléchargement échoue, la page reste intacte et un message dit pourquoi. Une vidéo de plus de 100 Mo est refusée. Si vous changez d'onglet pendant le téléchargement, rien n'est posé. Une adresse qui n'est pas une vidéo garde son comportement : l'image, ou le texte du lien.

Ouvrir la page dans le navigateur

Le bouton « ↗ » de la barre du cadre, ou la commande « Ouvrir le cadre dans le navigateur », ouvre l'adresse courante du cadre dans le navigateur du système, sans demander de confirmation. Si la page n'a pas encore chargé, c'est l'adresse saisie qui s'ouvre. Le bouton est grisé quand le cadre n'a pas d'adresse http ou https. Sous un verrou de classe, la commande est refusée.
