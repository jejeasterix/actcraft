Gomme

La gomme efface les traits à main levée qu'elle touche : elle les coupe là où elle passe. Elle ne touche ni les formes, ni les images, ni les textes.

Le choisir

Bouton de la gomme dans la palette, ou menu Outils, entrée Gomme, ou le raccourci Ctrl+E.

S'en servir

Promenez la gomme sur les traits à effacer, bouton enfoncé ou pointe posée ; relevez pour terminer. Tout le geste forme une seule étape : Ctrl+Z rend ce qui vient d'être effacé. Un trait verrouillé ou caché n'est pas touché. Au stylet ou à la souris, l'outil agit tout de suite. Au doigt, avec le mode du toucher réglé sur « full » (le réglage par défaut), un seul doigt conduit l'outil comme le stylet ; deux doigts posés ensemble déplacent ou zooment la page ; une paume posée pendant que le stylet est sur l'écran est ignorée.

Réglages

Pour effacer toutes les annotations d'une page d'un coup : menu Éditer, sous-menu Effacer, entrée Annotations.
