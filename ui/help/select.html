Sélectionner

L'outil de sélection désigne un ou plusieurs objets pour les déplacer, les redimensionner, les faire pivoter ou leur appliquer une commande.

Le choisir

Bouton en forme de flèche dans la palette, ou menu Outils, entrée Sélectionner, ou la touche Échap.

S'en servir

Touchez ou cliquez un objet pour le sélectionner. Pour en prendre plusieurs, tracez un cadre autour d'eux ou ajoutez-les un à un avec la touche Maj. Tirez l'objet pour le déplacer ; tirez une poignée pour le modifier. Touchez une zone vide pour tout désélectionner.

Réglages

Les commandes qui s'appliquent à la sélection (copier, supprimer, ordre des objets, verrouillage) se trouvent dans le menu Édition et dans le menu contextuel.
