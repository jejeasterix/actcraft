Connecteur

Le connecteur trace un lien entre deux objets. Le lien suit les objets quand on les déplace.

Le choisir

Bouton du connecteur dans la palette, ou menu Outils, entrée Connecteur, ou le raccourci Ctrl+Maj+C.

S'en servir

Posez le stylet, le doigt ou la souris sur le premier objet, tirez jusqu'au second, puis relevez. Déplacez ensuite l'un des objets avec l'outil de sélection : le lien reste attaché aux deux.

Réglages

Couleur et épaisseur du trait se choisissent dans la palette, comme pour le stylo.
