Pages et paquets de ressources

Un document est une suite de pages. Le navigateur de ressources range les images, les sons et les modèles ; glissez un élément sur la page pour l'y placer.

Outils de dessin, de sélection et de texte

La barre d'outils regroupe le stylo, le marqueur, la gomme, la sélection et le texte. Chaque outil garde ses réglages d'une session à l'autre. Une page par outil :

  • Stylo
  • Marqueur
  • Encre révélatrice
  • Gomme
  • Sélectionner
  • Formes
  • Texte
  • Texte de haut en bas
  • Pot de peinture
  • Connecteur

Profils et mode conception

Un profil choisit les commandes et les paramètres proposés. L'éditeur de profils permet d'en créer, d'en importer et de revenir aux réglages d'origine ; le mode conception donne accès à l'organisation de l'interface.

Documents récents et tableau d'accueil

Le tableau d'accueil liste les documents récents avec leur résumé et propose les actions courantes.

Mode classe protégé

Le verrouillage de la classe grise les commandes réservées à l'enseignant. Au premier verrouillage, ActCraft demande de créer un mot de passe (deux saisies) ; il n'existe aucun mot de passe par défaut. Pour déverrouiller, saisissez ce mot de passe.

Mot de passe de la classe oublié
