Mises à jour

Cette recherche existe sous Windows seulement.

Chercher une mise à jour

Menu Aide, entrée Rechercher des mises à jour…. ActCraft interroge la liste des versions publiées du projet et compare avec la version installée. Brouillons et préversions sont ignorés.

  • Si une version plus récente existe, la page de cette version s'ouvre dans le navigateur du système. ActCraft ne télécharge rien lui-même.
  • Si la réponse manque, est refusée ou est illisible, ActCraft le dit : impossible de vérifier.

Au démarrage

La recherche n'a lieu au démarrage que si le réglage du poste est activé ; il est désactivé par défaut.

Vie privée

Aucun identifiant ni donnée sur vous n'est envoyé. La requête suit le mandataire réglé pour l'application.
