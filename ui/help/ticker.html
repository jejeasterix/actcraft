Message défilant

Le message défilant fait passer un texte de droite à gauche sur une bande pleine largeur, une fois ou en boucle.

Le choisir

Menu Outils, sous-menu Autres outils, entrée Message défilant, ou le raccourci Ctrl+Maj+T : le message défile aussitôt avec les réglages courants, et la fenêtre de réglage s'ouvre.

S'en servir

Saisissez le message (ou ouvrez-en un enregistré), réglez-le, puis « Essayer » pour le rejouer sans rien garder, ou « Appliquer » pour garder ces réglages comme défaut et fermer la fenêtre. Pendant le défilement, « Pause » suspend le message et « Reprendre » le relance ; un clic droit sur la bande l'arrête. « Enregistrer le message » le garde dans un fichier de messages ActCraft.

Réglages

Position (haut, centre, bas), en boucle ou une seule fois, vitesse, police, taille, couleur du texte, ombre et fond (couleur ou écran transparent).
