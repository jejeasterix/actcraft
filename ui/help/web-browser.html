Navigateur web

Cette commande ouvre l'adresse d'accueil dans le navigateur web du système.

Le choisir

Menu Outils, sous-menu Autres outils, entrée Navigateur web.

S'en servir

La page s'ouvre dans le navigateur par défaut de l'ordinateur, hors de la fenêtre d'ActCraft ; revenez ensuite à ActCraft par le gestionnaire de fenêtres. Seules les adresses http et https sont ouvertes : toute autre adresse est refusée avec un message.

Réglages

L'adresse d'accueil est le réglage « tools/webHome ».
