Mot de passe de la classe oublié

Le verrouillage de la classe grise les commandes réservées à l'enseignant. Il se règle dans le menu Outils : Verrouiller pour la classe, et Mot de passe de la classe…. Au premier verrouillage, ActCraft demande de créer un mot de passe (deux saisies) ; il n'existe aucun mot de passe par défaut.

Le mot de passe n'est pas récupérable : seule une empreinte salée en est gardée. Pour retrouver l'accès :

  1. Fermez ActCraft.
  2. Dans la configuration de l'application (le fichier de réglages de l'utilisateur), supprimez toutes les clés dont le nom commence par classroom/ : classroom/hash, classroom/salt, classroom/iterations et classroom/locked.
  3. Relancez ActCraft : la classe est déverrouillée et le prochain verrouillage demande un nouveau mot de passe.
